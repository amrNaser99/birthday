# أجمل صدفة في عمري — الموقع

رابط الموقع: https://amrnaser99.github.io/birthday/

صورة QR المرتبطة بهذا الرابط: `dist/assets/qr-code.png`، ونسخة مستقلة: `QR-Website.png`.

## المعاينة المحلية

افتح Terminal داخل مجلد المشروع ثم شغّل:

```powershell
python -m http.server 8080 --directory dist
```

ثم افتح: `http://localhost:8080`

## إضافة الفيلم

ضع الفيديو النهائي في:

`dist/assets/our-story.mp4`

## إضافة الرسالة الصوتية

ضع التسجيل الصوتي في:

`dist/assets/voice-message.mp3`

يبدأ العد التنازلي حتى منتصف ليلة 14 نوفمبر 2026 بتوقيت القاهرة. بعد انتهاء العدّ، تبدأ حفلة صواريخ وكونفيتي مع Happy Birthday خفيفة باسم منى، ثم عدّ ٣–٢–١، وبعده تُشغّل الرسالة الصوتية ثم يظهر الفيلم ويبدأ تلقائيًا. يمكن معاينة الحفلة فورًا محليًا بإضافة `?preview=party` إلى الرابط، أو شاشة الرسالة فقط بإضافة `?preview=voice`.

موسيقى عيد الميلاد لحن فقط بدون غناء أو صوت بشري. تسجيلك الشخصي مستقل عنها، ويُشغّل إذا أضفت ملفه؛ عند غيابه ينتقل الموقع للفيلم مباشرة.

شاشة البداية والحفلة والرسالة الصوتية محسّنة للعرض الأفقي `16:9` على التلفزيون أو شاشة الكمبيوتر، مع تخطيط منفصل للموبايل.

ويمكن إضافة موسيقى اختيارية مرخصة في:

`dist/assets/ambient-music.mp3`

## الكارت

صورة الكارت الجاهزة للطباعة بمقاس A6 ودقة 300 DPI: `QR-Card-Print-Cropped.png`، ونسخة PDF: `QR-Card-A6.pdf`.
النسخة المصدرية في `dist/print-card.html`، ويمكن إعادة إنشاء الملفات بواسطة `scripts/generate-print-card.py`.
الـQR على الكارت يفتح رابط الموقع المنشور مباشرة، ولا يكشف عن الفيلم قبل المفاجأة.
